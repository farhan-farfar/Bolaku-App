# Bolaku-App
Bolaku is a mobile application for booking or renting sports fields, specifically for soccer, futsal, and mini soccer. The tagline is "Goals! Bookingnya, Goals! Mainnya!".

## 👥 Target Pengguna

| Aspek | Keterangan |
|---|---|
| Gender | Laki-laki |
| Usia | 15–40 tahun |
| Profesi | Karyawan, pelatih sepak bola, pelatih futsal, pelajar |
| Geografis | Pulau Jawa |
| Perilaku | Gemar bermain sepak bola/futsal, memilih fasilitas latihan terbaik, lebih suka pembayaran non-tunai, jadwal padat |

## ✨ Fitur Utama

- 🔐 **Sign Up & Sign In** (email atau akun Google/Facebook)
- 🔍 **Pencarian & filter lapangan** berdasarkan harga, lokasi, dan fasilitas
- 🏟️ **Lapangan populer** dan pilihan cabang olahraga (Sepak Bola, Mini Soccer)
- 📋 **Detail lapangan**: ukuran, jenis rumput, jam operasional, fasilitas, harga, dan ketersediaan
- ⭐ **Rating & ulasan** dari pengguna sebelumnya
- 🗓️ **Pemesanan lapangan** berdasarkan tanggal, lapangan, dan sesi, serta pilihan tambahan (sewa perlengkapan)
- 💳 **Pembayaran beragam**: e-wallet, transfer bank, kartu kredit
- 🧾 **Rincian & status pesanan**: Belum Bayar, Pesanan, Selesai
- ↩️ **Pembatalan pesanan dan refund**
- 👤 **Profil pengguna**: edit profil, ubah kata sandi, notifikasi, bantuan
